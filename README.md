# Explainable Machine Learning for Rainfall Prediction

## Overview
This research project evaluates explainable and robust machine learning models for rainfall prediction using WeatherAUS and NOAA weather data.

The study focuses on predictive performance, cross-dataset generalization, and model explainability.

## Machine Learning Models
- Logistic Regression
- Random Forest
- XGBoost

## Explainable AI
SHAP (SHapley Additive exPlanations) was used to analyze feature importance and explain model predictions at both global and local levels.

## Datasets
- WeatherAUS
- NOAA-derived weather dataset

Models were trained and evaluated on WeatherAUS data and externally evaluated using NOAA-derived data to test robustness under dataset shift.

## Results

### WeatherAUS
- XGBoost Accuracy: 90%
- XGBoost F1-score: 0.81
- Random Forest F1-score: 0.77
- Logistic Regression F1-score: 0.67

### Cross-Dataset Evaluation (NOAA)
- XGBoost Accuracy: 85%
- XGBoost F1-score: 0.70

XGBoost achieved the strongest performance and demonstrated better robustness under cross-dataset distribution shift.
